# Stock Price Analysis and Forecasting (Dissertation Project) 2024

## Overview
This repository contains my dissertation work on **stock price analysis and forecasting**, combining:
- exploratory and statistical analysis,
- interactive visualisation,
- and forecasting models to predict future price movement.

The emphasis is on **practical, reproducible analysis** and how forecasting outputs can support **data-driven decision-making** (risk assessment, trend monitoring, scenario planning).

## Project Context
- Dissertation submission: **August 2024**
- Artefacts in this repo:
  - `complete dissertation.Rmd` (full analysis pipeline)
  - `stockpriceanalysis.pdf` (final report export)

## Decision Problem
Financial time series are noisy and non-stationary. This project explores methods to:
- understand historical patterns and volatility,
- compare forecasting approaches,
- and evaluate predictive performance in a transparent, reproducible workflow.

## Methods (High-Level)
Typical steps included:
1. Data ingestion and cleaning
2. Exploratory analysis (returns, volatility, trend structure)
3. Visualisation (static + interactive)
4. Forecasting model development and evaluation

> Note: This is an applied academic project; the code and report are provided for transparency and reproducibility.
